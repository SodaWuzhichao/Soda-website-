SODA LiveGrabber

浏览器插件，直接在直播间页面抓取 FLV / M3U8 流地址，无需配置 Cookie，一次安装永久使用。

Why Extension

为什么推荐浏览器插件？

网页版存在的问题：抖音等平台的后端 API 会进行 IP 风控，网页版请求经常被拦截返回空结果。 插件方案完全不同——它运行在你本地的浏览器里，使用的是你已经登录的账号会话， 没有任何风控问题，也不需要配置 Cookie。
Installation

安装步骤

1
下载插件文件
点击下方按钮下载插件压缩包，解压后得到一个名为 browser-extension 的文件夹。
⬇ 下载插件包
2
打开浏览器扩展管理页面
根据你的浏览器，打开对应的管理页面：
🌐 Chrome
打开 chrome://extensions
🔵 Edge
打开 edge://extensions
3
开启开发者模式
在扩展管理页面右上角，找到「开发者模式」开关，将其打开。
4
加载已解压的扩展程序
点击「加载已解压的扩展程序」按钮，选择你刚才解压的 browser-extension 文件夹，确认即可。
5
开始使用
安装成功后，浏览器工具栏会出现 📡 图标。
打开任意直播间（抖音 / B站 / 快手），点击插件图标即可查看抓取的流地址并播放。

FAQ

常见问题

Q: 插件安装后闪退或没反应怎么办？
打开 chrome://extensions（或 edge://extensions），检查是否有红色错误提示。 常见原因：浏览器版本过低（需要 Chrome 88+ / Edge 88+），或开发者模式未开启。 也可以尝试移除后重新加载。
Q: 插件找不到流地址？
请确认你已在直播页面内（不是主播主页）。如果是在直播间但插件显示未检测到， 尝试按 F5 刷新页面，或打开 F12 开发者工具查看 Console 是否有报错信息。
Q: 插件会收集我的数据吗？
不会。插件完全在本地运行，只读取当前页面的网络请求来提取流地址，不上传任何数据到外部服务器。 Cookie 等认证信息也不会被插件读取或传输。
Q: 安装后如何更新？
在本页重新下载最新版本，然后在扩展管理页面点击「刷新」按钮（或移除旧版本后重新加载新版本）。
