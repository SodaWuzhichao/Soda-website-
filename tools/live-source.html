如何获取 Cookie
1. 浏览器打开对应平台并登录
2. 按 F12 → 切到 Application 标签 → 左侧 Cookies → 点对应域名
3. 全选所有条目 → 或在 Console 输入 document.cookie
4. 复制结果粘贴到上方输入框
Cookie 仅在本次请求中使用，不会上传或存储。

使用说明
  • 支持平台：抖音、快手、B站（免 Cookie）；淘宝、京东、小红书（需配置 Cookie）
  • 输入直播间主页链接或分享链接均可
  • 淘宝、京东、小红书需要 Cookie：选中平台后，粘贴自己的 Cookie 即可（不会存储）
  • 每 IP 每分钟最多 10 次解析，请合理使用
  • 流地址有时效性，建议解析后尽快使用
